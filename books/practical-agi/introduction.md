# はじめに

2026年1月、Sequoia Capital は「**Long-horizon agents are functionally AGI**（長期視野のエージェントは機能的にAGIである）」と宣言しました。

この宣言は、AGIの議論を哲学的な定義論争から、実用的な問題設定へと転換させるものでした。

## 本書の目的

本書では、Sequoia Capital が提唱した「実用AGI」の概念と、それを支える要素技術について解説します。

**実用AGI** とは、単に「人間のように賢いAI」ではありません。それは、**長時間・多段階のタスクを、試行錯誤しながら最後まで完遂できるエージェント** のことです。

## 実績: 41タスクを13時間で完了

実用AGIは机上の空論ではありません。著者が開発した **horizon agent** は、2026年1月に41個の開発タスクを処理し、以下の結果を出しました。

| 方式 | 所要時間 |
|------|---------|
| 人間が実装（見積もり） | 26〜47人日 |
| 人間がオーケストレーション + AI | 5日 |
| horizon agent | **13時間** |

**16〜29倍の効率化** です。

本書（概要編）では、この成果を支える理論と要素技術を解説します。
horizon agent の具体的な構成と作り方は、技術書典20で頒布予定の **実例編** で詳しく紹介します。
