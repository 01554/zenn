## 次の1文字を当てるだけの機械

LLM がやっているのは、1つの仕事の繰り返しです。

> これまでの文字列を見て、次に来る1文字を予想する。

これが全部です。「ふるいけや」まで来たら、次は何か。モデルは「あ」かもしれないし「の」かもしれない、と確率で答えます。そこから1文字を選び、末尾にくっつけて、また次の1文字を予想する。これを繰り返すと文章が生えてきます。この繰り返しを自己回帰（autoregressive）生成と呼びます（第10章）。

では、次の1文字を予想する一発ぶんの計算はどんな流れでしょうか。このモデルでは次の6ステップを通ります。

1. トークン化 … 文字を番号に変える（第3章）
2. 埋め込み … 番号を16個の数値（ベクトル）に変える（第4章）
3. アテンション … 前の文字たちを見て情報を集める（第5・6章）
4. MLP … 集めた情報を作り直す（第7章）
5. 出力 … 語彙ぶんの点数を出し、確率に直す（第8章）
6. サンプリング … 確率から1文字を引く（第9章）

このモデルはひらがな専用の小さな Transformer です。主なサイズは次のとおりで、以降の章で何度も出てきます。

| 記号 | 意味 | 値 |
|------|------|----|
| 語彙数 | 使う文字の種類（ひらがな＋開始記号） | 約81 |
| $d$ | 埋め込みの次元（1文字あたりの数値の個数） | 16 |
| ヘッド数 | アテンションの視点の数 | 4 |
| ブロック長 | 一度に見られる文字数（文脈の窓） | 16 |
| MLP 中間 | MLP が一時的に広げる幅 | 64 |
| 重みの総数 | 学習で調整される数値の個数 | 6080 |

Transformer のブロック（アテンション＋MLP のワンセット）は1段だけです。本物の GPT は同じブロックを何十段も積みますが、仕組みを理解するには1段で足りますし、Scratch で動かせる規模もこのあたりが上限です。

## 流れを目で見る

下の GIF は、実際のモデルが「ふるいけや」の続きを1文字生成していく様子です。上の6ステップが、この順番で流れます。

![生成の流れ（俯瞰）](/images/microgpt_on_scratch/inference.gif)

画面の見方を押さえておきます。以降の全チャプターで共通です。

- 左上のオレンジの帯：いま何をしているかのキャプション（`解説`）。
- 画面下の丸い点の列：注目している文字の16個の数値ベクトル。<span style="color:red">赤=負</span>、<span style="color:blue">青=正</span>、大きい丸ほど絶対値が大きい。これがモデルが保持している途中の状態で、ステップごとに書き換わっていきます。
- 右側の緑の棒グラフ：次の文字の候補トップ5。棒が長いほど確率が高い。
- 左の◆から続くひらがな：これまでに生成された文字列（ペンで描いています）。

ベクトルが書き換わっていって、最後に棒グラフから1文字が選ばれる。この大枠を頭に入れておけば、次章からの1手ずつの分解で迷子になりません。

## 1文字ぶんを一枚の絵にすると

1文字を生成する計算は、こう流れます。

```
文字列 ──[トークン化]──▶ 番号の列
      ──[埋め込み]──▶ 各文字が16個の数値に
      ──[アテンション]──▶ 前の文字の情報を混ぜ込む  ┐
      ──[足し算(残差)]──▶ 元のベクトルに足し戻す    │ ここが
      ──[MLP]──▶ 情報を作り直す                     │ Transformer
      ──[足し算(残差)]──▶ 元のベクトルに足し戻す    ┘ 1ブロック
      ──[出力の線形変換]──▶ 文字ごとの点数(ロジット)
      ──[ソフトマックス]──▶ 確率
      ──[サンプリング]──▶ 次の1文字
```

数式で書けば、いちばん最後の文字の位置のベクトル $\boldsymbol{x}$ に対して、

$$
\boldsymbol{x} \leftarrow \boldsymbol{x} + \mathrm{Attention}(\boldsymbol{x}), \qquad
\boldsymbol{x} \leftarrow \boldsymbol{x} + \mathrm{MLP}(\boldsymbol{x})
$$

という足し戻し（残差接続）を通し、最後に

$$
\text{確率} = \mathrm{softmax}(W_{\text{out}}\,\boldsymbol{x})
$$

で次の文字の確率を得ます。記号の意味は各章で1つずつ解きほぐしていきます。第3章、いちばん最初の入口のトークン化から始めます。
