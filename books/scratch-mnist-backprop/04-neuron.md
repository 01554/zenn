## ニューロン1個の計算

第2章の矢印の中身です。ニューロンと呼ばれる計算単位が、196個の入力から数を1個作ります。やることは重みつき足し算です。

```
z = 入力1 × 重み1 + 入力2 × 重み2 + …… + 入力196 × 重み196 + バイアス
```

入力それぞれに専用の重みを掛けて、ぜんぶ足して、最後にバイアスというゲタを1個足す。これだけです。

小さい例で確かめます。入力が3個で (1, 0, 1)、重みが (0.5, −0.3, 0.2)、バイアスが 0.1 なら、

```
z = 1 × 0.5 + 0 × (−0.3) + 1 × 0.2 + 0.1 = 0.8
```

重みがプラスのマスに黒（1）が来ると z は大きくなり、マイナスのマスに黒が来ると小さくなります。つまり重みの並びは「どのマスが黒いときに反応するか」という、そのニューロンの好みです。この好みを学習で作っていくわけです。

隠れ層1にはこのニューロンが8個あり、それぞれ自分専用の重み196個とバイアス1個を持ちます。層をまたぐたびに同じ計算がくりかえされて、196個 → 8個 → 4個 → 10個 と数が絞られていきます。

## 重みの総数を数える

- 入力196 → 隠れ層1（8個）：重み 196×8 = 1568個、バイアス 8個
- 隠れ層1（8）→ 隠れ層2（4個）：重み 8×4 = 32個、バイアス 4個
- 隠れ層2（4）→ 出力（10個）：重み 4×10 = 40個、バイアス 10個

合計 1662個。学習で直すのは、この1662個ぜんぶです。

## 1662個を1本のリストに入れる

Scratch のリストは1次元しかありません。層ごと・ニューロンごとに分けて持つと、リストが何十本にもなります（作者は前作でそれをやって懲りました）。そこでこの作品は、重みを `weights` という1本のリストに全部つなげて入れます。

```
weights = [ W1（1568個）| B1（8個）| W2（32個）| B2（4個）| W3（40個）| B3（10個）]
```

どこから何番目が W2 なのかを覚えておくために、各ブロックの開始位置（オフセット）を最初に計算してリストにしておきます。

| 中身 | 開始位置 | 個数 |
|------|---------|------|
| W1（入力→隠れ1の重み） | 1 | 1568 |
| B1（隠れ1のバイアス） | 1569 | 8 |
| W2（隠れ1→隠れ2の重み） | 1577 | 32 |
| B2（隠れ2のバイアス） | 1609 | 4 |
| W3（隠れ2→出力の重み） | 1613 | 40 |
| B3（出力のバイアス） | 1653 | 10 |

この表を作っているのが「動的モデルレイヤー」ブロックです。`LAYER_SIZE_LIST`（196, 8, 4, 10）から、各ブロックの大きさと開始位置を順に計算して `W_OFFSET_LIST` や `B_OFFSET_LIST` に入れていきます。

![層のサイズからオフセットを計算するブロック](/images/backpropagation_on_scratch/init/weight1.png)

![オフセット計算の続き](/images/backpropagation_on_scratch/init/weight2.png)

:::message
Scratch のリストは1番目から始まります。0番目はありません。この本に出てくる開始位置が全部1から数えてあるのはそのためです。0始まりのループと1始まりのリストが混ざるところがこの作品最大のバグの巣で、実際に踏んだ話を第13章でやります。
:::

## 途中の計算結果も1本のリストに

各層のニューロンが出した値も、`activations` という1本のリストにまとめて置きます。並びは入力層から順です。

| 中身 | 開始位置 | 個数 |
|------|---------|------|
| 入力（画像の196個） | 1 | 196 |
| 隠れ層1の出力 | 197 | 8 |
| 隠れ層2の出力 | 205 | 4 |
| 出力層の確率 | 209 | 10 |

こちらの開始位置は `A_OFFSET_LIST` に入っています。

## 重みつき足し算のブロック

ニューロン1個ぶんの重みつき足し算は、`z = Σ_i inputs[i]*W[i,j] + b[j]` という名前のブロックにまとめてあります（名前に記号が入っていますが、中身はいま見た掛け算と足し算のループです）。

![重みつき足し算ブロックの定義](/images/backpropagation_on_scratch/train/acc1.png)

読みどころは2つあります。

1つ目、合計を入れる変数 `u_sum_acc` は、最初にバイアスの値からスタートします。あとから足すのではなく、ゲタを先に履かせてから196回の掛け算を積んでいく書き方です。

2つ目、重みの取り出し方です。`p_w_offset + (番号 × 次の層の個数) + 何番目のニューロンか` という計算で、1本のリストから目当ての重み1個を取り出しています。オフセットで層の開始位置まで飛び、そこから掛け算で目的の場所を出す。この作品の中でいちばん何度も出てくる形なので、ここで慣れておくと後の章が楽になります。

![引数の意味。呼び出し前に p_ のついた変数へ値を入れておく](/images/backpropagation_on_scratch/train/acc2.png)

ブロック名の頭についている `p_` は、引数のかわりのグローバル変数の目印です。Scratch のブロック定義には戻り値がないので、この作品では「呼ぶ前に `p_〇〇` に材料を入れ、結果も `p_〇〇` で受け取る」という決まりで統一しています。

重みつき足し算はできました。ただ、これを何層重ねても、まだ足りないものがあります。次の章で、このモデル最大の工夫と一緒にそれを片づけます。
