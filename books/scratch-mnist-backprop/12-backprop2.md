## 隠れ層には正解がない

出力層のデルタは「確率 − 正解表」で作れました。ところが隠れ層1の8個のニューロンに、正解はありません。「2枚目の画像のとき、隠れ層の3番ニューロンは 0.7 を出すのが正しかった」なんて表はどこにもないのです。

そこで発想を変えます。隠れ層のニューロンの責任は、自分の値を受け取った次の層のデルタから逆算します。

```
隠れニューロンのデルタ =
  （次の層の各デルタ × そのニューロンへつながる重み）の合計
  × 自分のシグモイドの傾き
```

2つの部品でできています。順に見ます。

## 部品1：次の層から責任を受け取る

隠れニューロンの値は、次の層の全ニューロンに、それぞれ別の重みを掛けて渡っていました。だから次の層で起きた間違いのうち、自分に返ってくる責任は、

```
次のデルタ1 × 重み1 + 次のデルタ2 × 重み2 + …
```

という重みつき足し算になります。太い重みでつながっていた先の間違いは大きく返ってくるし、重みがほぼ 0 なら、その先で何が起きていようと自分には関係ありません。順伝播で値を配ったのと同じ経路を、責任が逆向きに流れてきます。「逆伝播」という名前はこの流れのことです。

## 部品2：シグモイドの傾きを掛ける

受け取った責任に、もうひとつ掛けるものがあります。順伝播で自分がシグモイドを通った、その地点での傾きです。

傾きとは「入力を少し変えたら、出力がどれだけ動くか」です。シグモイドの傾きは、いま出している値を a とすると、

```
シグモイドの傾き = a × (1 − a)
```

という掛け算1回で出ます。a = 0.5 のとき傾きは 0.25 で最大。a が 0.99 や 0.01 のときは傾きがほぼ 0 です。

なぜこれを掛けるのか。シグモイドが 0 や 1 に張りついているニューロンは、手前の重みを少し動かしても出力がほとんど変わりません。動かしても効かない場所の勾配は小さくあるべきで、傾きを掛けることでそれが自動的に反映されます。

![sigmoid と sigmoid導関数の定義。導関数のほうは a × (1 − a) の1行だけ](/images/backpropagation_on_scratch/util/sigmoid2.png)

## 隠れ層のデルタを作るブロック

![隠れ層の差分を計算の定義](/images/backpropagation_on_scratch/bwd/hidden_差分.png)

外のループが「この層の各ニューロン」、内のループが「次の層の各デルタ × 重み」の合計、最後に自分の値でシグモイドの傾きを掛けて `deltas` に書き込みます。式のとおりの二重ループです。

デルタができてしまえば、そこから勾配を作る方法は出力層とまったく同じです。バイアスの勾配はデルタのコピー、重みの勾配は入力側の値 × デルタ。第11章の2つのブロックをそのまま使い回します。

## 層をさかのぼるループ

あとは、これを出力側の隠れ層から順に繰り返すだけです。隠れ層2 → 隠れ層1 の順に、「デルタを計算 → バイアス勾配 → 重み勾配」を回します。

![s8_隠れ層更新の定義。層を1つずつさかのぼる](/images/backpropagation_on_scratch/bwd/s8.png)

`deltas` リストの中の並びは、計算する順に合わせて「出力層ぶん、隠れ層2ぶん、隠れ層1ぶん」の順です。`weights` や `activations` と並び順が逆なので、どこから始まるかを教える係のブロックが別にいます。

![u_get_delta_offset の定義。層の番号から deltas の開始位置を返す](/images/backpropagation_on_scratch/train/delta_offset.png)

## 逆伝播の完成

まとめ役の `s6_逆伝播` は2行です。

![s6_逆伝播の定義。出力層、次に隠れ層](/images/backpropagation_on_scratch/bwd/bwd1.png)

これで画像1枚につき、1662個の重み・バイアス全部の勾配が `grads` に揃いました。振り返れば、使った計算は掛け算・足し算・引き算と、`a × (1 − a)` の掛け算だけ。誤差逆伝播は名前も見た目もいかついですが、部品は中学校の計算です。

残るは、この勾配で実際に重みを動かすことだけです。
