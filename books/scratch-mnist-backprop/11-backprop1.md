## 責任という数を配る

損失を下げるには、1662個の重みそれぞれについて「お前を少し増やすと損失は増えるのか減るのか、どのくらいか」が知りたい。この数を勾配（こうばい）と呼びます。勾配さえわかれば、損失が減る向きに各重みを少し動かすだけです。

1662個ぶんの勾配を一気に求める手続きが誤差逆伝播です。出力側から入力側へ、答え合わせの結果を配りながらさかのぼるので「逆伝播」。順伝播とちょうど逆向きです。

配っていく途中の数をこの作品では「デルタ」と呼び、`deltas` というリストにためます。デルタは各ニューロンについた「今回の間違いへの関わりの大きさ」です。まず出力層の10個のデルタを作り（この章）、それを使って隠れ層のデルタを作ります（次章）。

## 出力層のデルタは引き算1回

いちばん複雑そうな出力層が、実はいちばん簡単です。

```
出力ニューロンのデルタ = そのニューロンが出した確率 − 正解表の値

正解表：正解の数字だけ 1、ほかは 0
```

正解が 3 の画像で、モデルが 3 に 0.2、7 に 0.5 をつけたとします。

```
3 のデルタ = 0.2 − 1 = −0.8    （もっと大きく出すべきだった）
7 のデルタ = 0.5 − 0 = +0.5    （出しすぎだった）
```

デルタがマイナスなら「このニューロンの値は上げたい」、プラスなら「下げたい」。ぴったり当てていれば 1 − 1 = 0 で、直すことはありません。外した大きさがそのまま直したい大きさになる、きれいな形です。

ソフトマックスと −log の組み合わせを微分すると、ちょうどこの引き算1回の形に化けます。式の導出は『ゼロから作る Deep Learning』の付録に丸ごと載っているので、理屈を追いたくなったらそちらへ。この本では「確率から正解表を引くだけ」という結果を使います。

![出力層の差分計算の定義。確率を取り出し、正解の番号のときだけ 1 を引く](/images/backpropagation_on_scratch/bwd/output_差分.png)

ループの中の「もし 番号 = 正解ラベル なら 1 を引く」が正解表の役目をしています。10個の 0/1 のリストをわざわざ作らずに、if で済ませているわけです。

## デルタから勾配へ

出力層のデルタ10個ができました。ここから、この層につながる重み40個とバイアス10個の勾配を作ります。どちらも1行です。

```
バイアスの勾配 = そのニューロンのデルタ
重みの勾配   = その重みの入力側の値 × 出力側ニューロンのデルタ
```

バイアスは、そのニューロンに直接足されるゲタなので、責任はデルタそのままです。

重みはどうか。重みが今回の答えにどれだけ関わったかは、その重みを通った値の大きさで決まります。入力側の値が 0 だったなら、その重みは今回何もしていません。何もしていない重みの勾配は 0 になり、動かされません。入力側の値が大きかった重みほど今回の間違いに深く関わっているので、大きく直されます。掛け算1回がその理屈をそのまま表しています。

![勾配を作る2つのブロック。バイアスはコピー、重みは入力×デルタ](/images/backpropagation_on_scratch/util/util_grad.png)

上の `u_copy_delta_to_bias_grad` がバイアス用のコピー、下の `u_calc_weight_gradient` が重み用の掛け算ループです。結果は `grads` というリストにためます。`grads` は `weights` と同じ1662個・同じ並びで、あとで「weights の n 番目から grads の n 番目ぶんを引く」だけで更新できるようにしてあります。

## 出力層ぶんをまとめて呼ぶ

![s7_出力層更新の定義。差分計算→バイアス勾配→重み勾配の順に呼ぶ](/images/backpropagation_on_scratch/bwd/s7.png)

オレンジの行が多いのは、いつもどおりオフセットの受け渡しです。デルタの計算、バイアス勾配、重み勾配の3ブロックを順に呼んでいるだけで、新しい計算はありません。

これで、出力層に直接つながる重み40個＋バイアス10個、計50個の勾配が出ました。残り1612個は隠れ層の側にあります。そこには「正解表」がありません。次の章で、その壁を越えます。
