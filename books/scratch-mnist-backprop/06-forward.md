---
title: "順伝播：画像から10個の点数を出す"
---

## 部品を層の形に組む

ここまでで、重みつき足し算（第4章）とシグモイド（第5章）ができました。この2つを層の形に組んで、画像1枚を10個の点数に変換します。入力から出力へ向かって計算が進むので、順伝播（じゅんでんぱ）と呼びます。

やることを1行で書くと、こうです。

```
各層の各ニューロンについて：
  z = 前の層の値の重みつき足し算
  出力 = sigmoid(z)
  activations リストの自分の場所に書き込む
```

## 層をめぐるループ

いちばん外側のブロックが `s1_順伝播` です。隠れ層を順にめぐって、最後に出力層を呼びます。

![s1_順伝播の定義。層ごとにオフセットを用意して s2 を呼ぶ](/images/backpropagation_on_scratch/fwd/s1.png)

オレンジのブロックがたくさん並んでいますが、やっていることは材料の受け渡しです。いまの層の「入力は何個か・ニューロンは何個か・重みはリストの何番から始まるか」を第4章のオフセット表から取り出して、`p_input_size` などの引数変数に置いているだけです。準備ができたら `s2_隠れ層を順伝播` を呼び、層の番号を1つ進めて繰り返します。

## 隠れ層1層ぶん

![s2_隠れ層を順伝播の定義](/images/backpropagation_on_scratch/fwd/s2.png)

こちらが実働部隊です。ニューロンの数だけ繰り返して、

1. 重みつき足し算ブロックで z を計算
2. sigmoid ブロックで 0〜1 に変換
3. `activations` の自分の場所（この層の開始位置 + 自分の番号）に書き込み

をやります。第4章と第5章の部品をそのまま呼んでいるだけで、新しい計算はもうありません。

## 出力層だけ少し違う

![s3_出力層を順伝播の定義](/images/backpropagation_on_scratch/fwd/s3.png)

最後の層（4個 → 10個）も重みつき足し算までは同じですが、シグモイドを通しません。z の値を `output_z_arr` という10個のリストにそのまま置きます。

この10個が、モデルの生の点数です。たとえばこんな数が並びます。

```
0: −1.2   1: 0.3   2: 4.1   3: −0.5   …   9: 1.8
```

いちばん大きい点数の数字（この例では 2）がモデルの答えです。ただ、学習のためには「答えは 2、自信は 78%」のような確率の形が要ります。点数を確率に変えるのが次の章のソフトマックスで、`s3` の最後で呼ばれているのがそれです。

## 数の流れを目で追う

順伝播1回で起きることを数えておきます。

- 入力196個 → 隠れ層1：重みつき足し算8回（掛け算 196×8 = 1568回）+ シグモイド8回
- 隠れ層1 → 隠れ層2：重みつき足し算4回 + シグモイド4回
- 隠れ層2 → 出力：重みつき足し算10回

画像1枚で掛け算が1600回あまり。人間なら1日仕事ですが、これでもニューラルネットワークとしては極小です。ChatGPT 級のモデルは、同じ形の計算を1回の返事のたびに何兆回もやっています。やっている計算の種類は、いま組んだこれと同じです。
