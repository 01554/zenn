## この本でやること

手書きの数字を見て「これは 2 だ」と当てるAIを、Scratch 3 だけで作ります。拡張機能は使いません。

この本の作品は、1つの Scratch プロジェクトに2つの顔を持たせてあります。

- **推論モード**：緑の旗を押すと14×14のマス目パネルが並びます。マウスで数字を書いて「すいろん」ボタンを押すと、AIが答えを言います。
- **学習モード**：画面の「学習フラグ」を 1 にして旗を押すと、AIの中身（重み）を白紙に戻し、600枚の手書き数字を教材にゼロから学習し直します。まちがいから自分で重みを直していくこの仕組みが誤差逆伝播（ごさぎゃくでんぱ、バックプロパゲーション）で、ChatGPT のような大きなAIも、根っこでは同じ方法で学習しています。

![数字を書いて「すいろん」を押すと、AIが答える](/images/scratch-mnist-backprop/stage_v4_suiron.png)

開いてすぐの状態でも数字を当てられるのは、学習済みの重み1662個をあらかじめ焼きこんであるからです。そしてこの重みは、Python でもライブラリでもなく、**この本の後半で組む学習モードが Scratch の中で自力で作ったもの**です。テスト100枚で正解率62.4%。でたらめに答えれば10%（数字は0〜9の10種類だから）なので、学習だけで6倍賢くなった状態から始まります。

この本は、その中で起きていることを、部品の1個目から1ブロックずつ組み立てて確かめていきます。

## 参考にした本

このモデルの作りは『ゼロから作る Deep Learning』（斎藤康毅、オライリー・ジャパン）の3層ニューラルネットワークと誤差逆伝播の章をもとにしています。あの本は Python で作りますが、この本は同じものを Scratch のブロックで作ります。

## なぜ Scratch なのか

Python の勉強にもなる題材を、わざわざ Scratch でやる理由が2つあります。

1つ目。Scratch は中身が全部見えます。重みのリストも、途中の計算結果も、実行中ずっと画面に出しておけます。学習が進むにつれて数値が変わっていく様子を、目で見られます。

2つ目。Scratch にはライブラリがありません。Python なら1行で済む計算も、自分で足し算と掛け算のループを組むことになります。めんどうですが、そのおかげで「ニューラルネットワークに本当に必要な計算はこれだけだ」というのが体でわかります。

## 数学が苦手でも作れる理由

この本は、読者が中学生でも読めるように書きます。数式の記号は使いません。使う計算は、足し算・引き算・掛け算・割り算の4つだけです。

ただし、途中で exp（エクスポネンシャル）と log（ログ）という2つの関数が出てきます。高校で習う関数で、四則演算だけでは計算できません。

ここにこの本のいちばん大事な工夫があります。**計算できない関数は、計算しません。** Python に先に計算させて、答えを2万行の表にして、Scratch のリストに読み込んでおきます。あとは「exp(2.934) が欲しければ表の12935番目を見る」という引き算と掛け算だけの表引きで済みます。計算式の意味がわからなくても、表さえあればニューラルネットワークは組めます。やり方は第5章で、Python のコードごと見せます。

## この本の読み方

各章は、だいたい次の順で進みます。

1. やりたいこと（何のための計算か）
2. 計算のかたち（足し算と掛け算でどう書けるか）
3. 実際のブロック（Scratch でどう組んであるか、画面つき）

前半（第3〜8章）で推論モードを、後半（第9〜14章）で学習モードを組み上げます。構成は次のとおりです。

| 章 | テーマ | ひとことで言うと |
|----|--------|------------------|
| 2 | 全体像 | 2つのモードと、数の流れを俯瞰する |
| 3 | 入力パネル | 14×14のマス目をクローンで作る |
| 4 | ニューロン | 重みつき足し算 |
| 5 | 表引き | exp と log を計算せずに手に入れる |
| 6 | 順伝播 | 画像から10個の点数を出す |
| 7 | ソフトマックス | 点数を確率に変える |
| 8 | すいろんボタン | 推論モードの完成 |
| 9 | 学習データ | MNIST を Scratch に持ち込む |
| 10 | 損失 | どれくらい外したかを1つの数にする |
| 11 | 逆伝播（出力層） | 答え合わせから修正量を作る |
| 12 | 逆伝播（隠れ層） | 修正量を後ろへ配る |
| 13 | 更新と学習ループ | 少しずつ直して、繰り返す |
| 14 | バグとの戦い | 実際に踏んだバグと、その見つけ方 |
| 15 | おわりに | 層をいじって遊ぶ |

この作品の原型になった2つのプロジェクトも Scratch のサイトで公開してあります。推論だけの前作と、学習だけの前作です。本書の作品は、この2つを1つにまとめたものです。

- 推論機（Python で学習した重みを移植したもの）：https://scratch.mit.edu/projects/1252363057/
- 誤差逆伝播学習機：https://scratch.mit.edu/projects/1253455000/
