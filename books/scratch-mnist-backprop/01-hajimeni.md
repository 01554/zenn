## この本でやること

手書きの数字の画像を見て「これは 2 だ」と当てるAIを、Scratch 3 だけで作ります。拡張機能は使いません。

当てるだけではありません。この本の主役は学習です。最初はデタラメな答えしか出せないニューラルネットワークに、600枚の手書き数字を何度も見せて、まちがいから自分で重みを直させます。この直し方が誤差逆伝播（ごさぎゃくでんぱ、バックプロパゲーション）で、ChatGPT のような大きなAIも、根っこでは同じ方法で学習しています。

完成品は Scratch のサイトで公開してあります。緑の旗を押すと学習が始まり、終わるとテスト100枚での正解率が出ます。

https://scratch.mit.edu/projects/1253455000/

![学習が終わった画面。エポックごとに損失が下がり、テスト正解率は72%](/images/debug_backpropagation/完成.png)

でたらめに答えると正解率は10%です（数字は0〜9の10種類だから）。それが学習だけで70%を超えるところまでいきます。この本は、その中で起きていることを1ブロックずつ確かめていきます。

## 参考にした本

このモデルの作りは『ゼロから作る Deep Learning』（斎藤康毅、オライリー・ジャパン）の3層ニューラルネットワークと誤差逆伝播の章をもとにしています。あの本は Python で作りますが、この本は同じものを Scratch のブロックで作ります。

## なぜ Scratch なのか

Python の勉強にもなる題材を、わざわざ Scratch でやる理由が2つあります。

1つ目。Scratch は中身が全部見えます。重みのリストも、途中の計算結果も、実行中ずっと画面に出しておけます。学習が進むにつれて数値が変わっていく様子を、目で見られます。

2つ目。Scratch にはライブラリがありません。Python なら1行で済む計算も、自分で足し算と掛け算のループを組むことになります。めんどうですが、そのおかげで「ニューラルネットワークに本当に必要な計算はこれだけだ」というのが体でわかります。

## 数学が苦手でも作れる理由

この本は、読者が中学生でも読めるように書きます。数式の記号は使いません。使う計算は、足し算・引き算・掛け算・割り算の4つだけです。

ただし、途中で exp（エクスポネンシャル）と log（ログ）という2つの関数が出てきます。高校で習う関数で、四則演算だけでは計算できません。

ここにこの本のいちばん大事な工夫があります。**計算できない関数は、計算しません。** Python に先に計算させて、答えを2万行の表にして、Scratch のリストに読み込んでおきます。あとは「exp(2.934) が欲しければ表の12935番目を見る」という引き算と掛け算だけの表引きで済みます。計算式の意味がわからなくても、表さえあればニューラルネットワークは組めます。やり方は第5章で、Python のコードごと見せます。

## この本の読み方

各章は、だいたい次の順で進みます。

1. やりたいこと（何のための計算か）
2. 計算のかたち（足し算と掛け算でどう書けるか）
3. 実際のブロック（Scratch でどう組んであるか、画面つき）

構成は次のとおりです。

| 章 | テーマ | ひとことで言うと |
|----|--------|------------------|
| 2 | 全体像 | 学習1回ぶんの流れを俯瞰する |
| 3 | 入力パネル | 14×14のマス目をクローンで作る |
| 4 | ニューロン | 重みつき足し算 |
| 5 | 表引き | exp と log を計算せずに手に入れる |
| 6 | 順伝播 | 画像から10個の点数を出す |
| 7 | ソフトマックス | 点数を確率に変える |
| 8 | 学習データ | MNIST を Scratch に持ち込む |
| 9 | 損失 | どれくらい外したかを1つの数にする |
| 10 | 逆伝播（出力層） | 答え合わせから修正量を作る |
| 11 | 逆伝播（隠れ層） | 修正量を後ろへ配る |
| 12 | 更新と学習ループ | 少しずつ直して、繰り返す |
| 13 | バグとの戦い | 実際に踏んだバグ2つと、その見つけ方 |
| 14 | おわりに | 層をいじって遊ぶ |

では、まず全体を眺めるところからです。
